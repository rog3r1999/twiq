What you can edit

Headings and paragraphs can be edited directly. Press Enter when you are done; the Changes tab in the panel lists everything you changed. Press Cmd/Ctrl+S to save.

Paragraphs with bold and emphasis can be edited too, and the formatting stays as it was.

What you cannot edit

A script on the page produces the number below, so it is not in the source. Select it and click again to see why:

Text inside a code block (pre) cannot be edited yet:

function hello() {
  return 'Hello, Twiq'
}

Saving changes only the characters you changed; every other byte of the file stays the same. Saving the sample page asks where to put it.
