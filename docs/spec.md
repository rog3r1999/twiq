## 0. 本版说明与评审结论

- 本版是完整、独立的规格，不需要对照 v1 阅读。验收只看第 16 节（功能验收 AC-01 起，体验验收 UX-01 起），其余章节是实现依据。
- 默认桌面端优先（macOS、Windows）。触屏与手机不在范围内。
- 措辞约定：「必须」= 不做就不通过验收；「应该」= 强烈建议；「可以」= 可选。
- 评审方法：通读了两个 demo（editor.html 与 html-editor (2).html，二者除「清理微信」功能外基本相同），逐项对照 v1，结论如下。

### 0.1 评审结论（v1 到 v2 的 12 处变化）

1. **采用 demo 的交互骨架**：悬停、选中、编辑三级反馈；选中框带标签；底部面包屑；贴近元素的浮动工具条；拖放指示线；操作后的轻提示（toast）。v1 只有「点击就编辑」，缺少这些反馈，用户很难知道哪里能点、点了会怎样。
2. **不采用 demo 的保存方式**：demo 用整页序列化（对整个 DOM 取 outerHTML）保存，会重排格式、改写属性与实体，并固化浏览器的纠错结果。这与「只改被改字符」的核心承诺冲突，v2 继续使用 v1 的源码补丁路线。
3. **不采用 demo 的撤销方式**：demo 保存 body.innerHTML 快照（最多 50 步），只管 body、占内存、会重置页面状态。v2 用补丁式撤销，同时吸收 demo 的好做法：连续微调 600ms 合并成一步。
4. **叠加层放进页面内**：demo 在 iframe 外画叠加层，靠逐帧循环同步坐标。v2 的预览是独立视图，叠加层由 preload 在页面内用隔离的影子 DOM 绘制，滚动与缩放天然同步，不需要逐帧同步坐标。
5. **Esc 与 Enter 的行为改变**：v1 的 Esc 是放弃修改，容易误丢内容。v2 改为 Esc 和 Enter 都表示「完成编辑并保留修改」，想撤回用撤销。
6. **允许编辑中的原生撤销**：v1 一律拦截 Cmd/Ctrl+Z。v2 在编辑过程中允许浏览器按字词撤销；文字回到进入编辑时的状态后，再按一次才撤销上一步应用级操作。
7. **未保存标记提前**：v1 提交后才出现「●」。v2 在第一次输入时就出现，避免用户在编辑中途关闭窗口而丢失内容。
8. **新增多标签页**：demo 支持多文档标签，桌面端用户经常同时改几份 AI 生成的页面。每个标签有独立的预览、撤销栈、未保存状态。
9. **新增空状态、示例文档、拖拽打开提示、最近文件、原生菜单、窗口状态记忆**：v1 缺失，属于桌面软件的基本盘。
10. **新增完整的视觉规范**：色板、线宽、层级、动效、浮动工具条的定位算法，全部给出数值。字体改用系统字体栈，不依赖联网字体（demo 引用了 Google Fonts，离线时会退化）。
11. **新增键盘与无障碍规范**：焦点顺序、快捷键全表、屏幕阅读器标注、减少动效。
12. **版本路线按 demo 能力重排**：demo 里的块选择、换位、尺寸、微调、文字格式、媒体、粘贴导入，分别放进 v0.2 到 v0.4，并说明每一项在「源码补丁」路线下怎么实现（见第 3 节和第 20 节）。媒体不再默认以 base64 内嵌，因为会让文件膨胀、diff 无法阅读。

### 0.2 v2.1 修订（2026-10-20，已决事项 D1–D6）

- **原则：编辑产品优先**。HTML 写法约束不进入 v0.1 的产品功能，整理为附录 A，供后续宣传、使用介绍与 demo 演示使用。
- **D1 产品立场**：兼容任意 HTML。推荐写法只作为对外材料（附录 A）；v0.1 界面内不做写法引导，不做强制的组件规范。
- **D2 覆盖率样本**：未加约束的原始样本集作为 80% 门槛；用附录 A.3 提示词生成的约束样本集单列，作为参考指标（17.4）。
- **D3 资源根目录**：默认为 HTML 所在目录；页面引用上级目录的资源时提示一次，用户可授权某个上级目录作为资源根（第 14 节）。
- **D4 内联白名单扩充**：加入 del、ins、label、button；input 视为原子内联元素（13.4）。
- **D5 脚本渲染页面**：在浏览器端由 React、Vue、Alpine 等渲染正文的页面明确不支持；覆盖率统计中单列，不计入门槛；打开时提示一次（4.2、10.6、17.4）。
- **D6 BLOCK_CHILDREN 是否放宽（原 Q4）**：覆盖率脚本提前到 M1，按初测数据决定（18、19.1）。
- **其他修订**：Tab 与 Shift+Tab 跳过不可见的 host（7.3、11.2）；修正 hw:// 协议对 ../ 的处理。原写法使用固定入口 hw://doc/index.html，浏览器会先把超出根的 ../ 规范化掉，越界请求无法识别，还会被静默映射到目录内的同名文件（见第 14 节）。

## 1. 产品定位与成功标准

- 一句话：一个桌面应用，打开本地静态 HTML 文件，在渲染好的页面上直接点击修改文字；保存时只改动被改的那几个字符，文件其余部分一字节不变。
- 要解决的问题：AI 生成的 HTML 页面，想改几个字，要么重新让 AI 生成一遍，要么去源码里手动找。
- 与 Typora 的关系：借鉴「所见即所得、点哪改哪」的体验，对象是 HTML，不是 Markdown。
- 功能成功标准（缺一不可）：
  1. 真实 AI 生成页面样本集上，页面可见文字至少 80% 可编辑。
  2. 编辑并保存后，diff 只出现被改文字所在的行。
  3. 连续编辑 50 次再撤销 50 次后，文件与最初逐字节相同。
- 体验成功标准（缺一不可）：
  1. 首次使用、无任何指导，新用户 60 秒内完成「打开、改一个字、保存」（5 名新用户测试，至少 4 人成功）。
  2. 任何一次点击，用户都能在 200ms 内看到反馈（高亮、编辑框、气泡或提示）。
  3. 任何被拒绝的操作，都有一句人话说明原因和下一步，不出现静默失败。
  4. 任何误操作，都能用 Cmd/Ctrl+Z 一步回到之前，且不丢失已输入的文字。

## 2. 用户与场景

- 主要用户：用 AI 生成网页、简报、落地页、报告的人，包括不懂代码的运营、设计、产品，以及懂一点代码但不想每次都读源码的人。
- 使用环境：桌面端，一般同时开着 AI 对话窗口和本编辑器。

### 场景 S1：改文案（最高频）

1. 用户把 AI 生成的 report.html 拖到应用窗口。
2. 页面按原样出现。鼠标掠过标题，出现蓝色虚线框。
3. 点击标题，光标落在点击位置，框变为绿色实线，可直接输入。
4. 按 Enter 完成；标签上出现未保存圆点。
5. Cmd/Ctrl+S 保存，提示「已保存」。用 git diff 查看，只有那一行变化。

### 场景 S2：不确定哪里能改

1. 用户点击一段由脚本生成的数字。
2. 该处显示灰色虚线框，气泡写明原因「这段文字由页面脚本生成，无法安全写回源码」，并给出下一步「请在生成它的数据或脚本里修改」。
3. 用户不会以为软件坏了。

### 场景 S3：AI 在后台改文件，用户同时在编辑

1. 用户正在编辑页面，AI Agent 重新写了同一个文件。
2. 用户没有未保存修改：页面静默刷新，滚动位置保留，提示「已从磁盘更新」。
3. 用户有未保存修改：弹出三选一对话框，不丢任何一方的内容。

## 3. 对 demo 的评审：采用、改造、不采用

### 3.1 采用并改造

- **悬停高亮与选中框**：悬停 1px 虚线框；选中 1.5px 实线框加 3px 淡色光晕；左上角标签显示「标签名#id」；距顶部不足 24px 时标签改放框内。v0.1 用于编辑块，v0.2 扩展到任意元素。
- **面包屑**（底部，形如 body › section.hero › h1，可点击选中祖先）：v0.1 只显示、不可点击（祖先不可编辑，点了没反应是坏体验）；v0.2 起可点击。
- **浮动工具条**：贴在元素上方，放不下改放框内顶部，再放不下贴可见底边，最后夹紧在视口内。v0.1 只有一个很小的工具条（见 8.6），v0.3 起放文字格式。
- **模式切换**（demo 为 组件 / 文字 / 浏览）：v0.1 只保留「编辑 / 预览」两种；v0.2 起增加「选择」模式。借用 demo 的两个小手势：Tab 在模式间切换（v0.2 起）、Alt+点击临时放行页面自身的点击。
- **轻提示 toast**：底部居中，2.2 秒消失，同一时刻只显示一条。
- **多文档标签、拖入文件的全屏提示、空状态三个入口（打开 / 新建 / 载入示例）、示例文档、状态栏随模式变化的操作提示**：全部采用。
- **显示空白组件**（粉色虚线框标出没有文字也没有媒体的容器）：v0.2 采用，用于选中空容器；v0.1 不需要。
- **连续微调合并撤销**：采用，600ms 内的连续同类操作合并为一步。
- **尺寸手柄与尺寸提示**（拖动时显示「宽 × 高」）：v0.3 采用交互，宽高写入 style 属性（源码补丁，只改该属性）。
- **方向键微调**（1px，Shift 为 10px）：v0.4 采用，明确标注为「视觉偏移，不改文档流」。

### 3.2 不采用

- **整页序列化保存、body 快照撤销**：见 0.1 第 2、3 条。
- **WPS 式功能区（开始 / 插入 / 文档）**：不采用。理由：占用垂直空间；与浮动工具条重复（demo 里 B/I/U 出现了两处）；视线要在顶部功能区和页面之间来回跳。替代：v0.1 用精简工具栏；v0.3 起用右侧属性面板承载样式。
- **媒体默认转 base64 内嵌**：不采用。会让文件膨胀、diff 无法阅读。v0.3 改为复制到同目录 assets/ 并写相对路径。
- **清理微信文章**：业务特定，不做。
- **联网字体**：不采用，改用系统字体栈。
- **用 execCommand 做文字格式**（会生成 font、span 与冗余样式）：不采用。v0.3 的文字格式改为由补丁引擎生成受控的内联标签（b、i、u、s、sub、sup），不依赖浏览器的 execCommand。
- **另存为 Markdown / 纯文本**：v0.5 再议；v0.2 先提供导出 PDF（桌面端有原生打印到 PDF）。

8. 不可编辑文字的原因提示。
9. 空状态、示例文档、拖拽提示、toast、对话框、原生菜单、窗口状态记忆。
10. 键盘可达与无障碍基础项。

### 4.2 v0.1 明确不做

- 不改标签、属性、样式；不增删或移动元素；不替换图片；不做文字格式（加粗、颜色等）。
- 不做组件规范、生成约束、界面内的写法引导、AI 接口、插件；界面只有中文。推荐写法整理为附录 A，作为宣传与 demo 材料，不是产品功能。

## 5. 名词定义

- **真源**：磁盘上的 HTML 文件。内存里的源码缓冲区（下称 source）是它的副本。预览永远只是真源的「投影」。
- **元素 ID（eid）**：解析 source 时，按文档顺序给每个在源码中显式写出了起始标签的元素编号 0、1、2……。同一份源码无论解析多少次，编号都相同。
- **文字槽（slot）**：一个元素里，相邻两个子元素之间（含首个子元素之前、末个子元素之后）的那段文字。有 m 个子元素的元素有 m+1 个槽，编号 0 到 m；没有子元素的元素只有槽 0。槽可以是空的。例：`<p>甲<b>乙</b>丙</p>` 中，p 有槽 0（甲）和槽 1（丙）；b 只有槽 0（乙）。
- **编辑块（host）**：用户一次点击所进入编辑的那个元素，判定规则见 13.4。
- **操作（op）**：对一个槽的整体替换，写作 setSlot(eid, slot, newText)。
- **补丁（patch）**：由 op 换算出的、对 source 的区间替换，形如 {start, end, text}。
- **可编辑 / 不可编辑**：槽属于某个 host，并通过 13.6 的校验，则可编辑；否则不可编辑，并带一个原因代码（见 10.5）。
- **带标注副本**：仅用于预览的 HTML 副本，在每个元素起始标签里插入 data-hw 属性。只存在于内存，不写回磁盘。
- **叠加层（overlay）**：预览页内、由 preload 创建的影子 DOM 容器，负责画悬停框、编辑框、标签、气泡、浮动工具条。它不参与页面布局，不拦截未处理的鼠标事件。
- **选中（selection）**：当前被选中的元素。v0.1 中只有 host 可以被选中；编辑中的 host 同时是选中元素。
- **悬停（hover）**：鼠标指针下方的目标元素（可编辑 host，或不可编辑但含文字的元素）。
- **标签页（tab）**：一份打开的文档，拥有独立的 source、撤销栈、预览视图。

## 6. 窗口布局与信息架构

### 6.1 总体布局（桌面，从上到下）

```
┌────────────────────────────────────────────────────────────────┐
│ 工具栏 44px：打开 保存 ｜ 撤销 重做 ｜ 编辑/预览 ｜ 视口 缩放      │
├────────────────────────────────────────────────────────────────┤
│ 标签栏 36px：● report.html ×　index.html ×　+                    │
├────────────────────────────────────────────────────────────────┤
│                                                                │
│               预览区（页面 + 页内叠加层）                         │
│                                                                │
├────────────────────────────────────────────────────────────────┤
│ 状态栏 28px：面包屑 / 路径　　　　操作提示　　　　　保存状态        │
└────────────────────────────────────────────────────────────────┘
```

### 6.2 各区域规格

- **窗口**：默认 1280×800；最小 960×600；记住上次的位置、大小、是否最大化、预览缩放比例、视口宽度选项（按应用记住，不按文档）。
- **标题栏**：使用系统原生标题栏。标题格式「文件名 — HtmlWrite」；有未保存修改时前缀「● 」。macOS 同时设置原生的 documentEdited 状态（关闭按钮上显示小圆点）。
- **工具栏（高 44px）**：从左到右依次为：打开、保存、分隔线、撤销、重做、分隔线、模式切换（分段控件：编辑 / 预览）、弹性空白、视口宽度下拉、缩放控件（减号、百分比、加号）。每个按钮：图标 + 文字（宽度够时显示文字），悬停 400ms 显示提示，内容含快捷键。按钮最小点击区 32×32。
- **标签栏（高 36px）**：每个标签显示文件名（最长 18 字符，超出中间省略）、未保存圆点、关闭按钮（悬停或当前标签才显示）；中键点击关闭；拖动标签可重排；标签超出宽度时水平滚动，不收起。最后有「+」按钮（新建空白文档）。只有 1 个标签时标签栏仍显示，保持布局稳定。
- **预览区**：占满剩余空间。预览底色固定为浅灰（#F0F1F3）。视口宽度为「自适应」时页面宽度等于预览区宽度；选择桌面 1280、平板 768、手机 390 时，页面居中，两侧显示灰底。
- **状态栏（高 28px）**：左侧为面包屑（有选中元素时）或文件完整路径；中间为当前状态的操作提示（见 10.4）；右侧为保存状态（已保存 / 未保存 / 只读）。字号 12px，面包屑用等宽字体。

### 6.3 原生菜单

macOS 为系统菜单栏；Windows 为窗口顶部菜单（可隐藏，按 Alt 唤出）。

- **文件**：新建空白文档 Cmd/Ctrl+N；打开… Cmd/Ctrl+O；打开最近文件（最多 10 个，末尾有「清除菜单」）；保存 Cmd/Ctrl+S；另存为… Cmd/Ctrl+Shift+S；在访达 / 资源管理器中显示；关闭标签页 Cmd/Ctrl+W。
- **编辑**：撤销、重做、剪切、复制、粘贴、全选（编辑文字时作用于文字，否则撤销与重做作用于应用级撤销栈）。
- **查看**：编辑 / 预览模式切换 Cmd/Ctrl+E；放大 Cmd/Ctrl+加号；缩小 Cmd/Ctrl+减号；实际大小 Cmd/Ctrl+0；重新加载磁盘文件 F5；开发者工具（仅开发构建）。
- **窗口**：最小化、缩放；下一个标签 Ctrl+Tab，上一个标签 Ctrl+Shift+Tab（macOS 同样使用 Ctrl）。
- **帮助**：快捷键列表 F1；载入示例文档；关于。

## 7. 交互状态机

### 7.1 全局模式（每个标签独立）

- **编辑模式**（默认）：叠加层开启；页面自身的点击、表单提交、链接跳转被拦截。
- **预览模式**：叠加层关闭；页面自身的交互全部放行；外链点击先确认。
- 切换：Cmd/Ctrl+E，或工具栏分段控件「编辑 / 预览」。临时放行：编辑模式下按住 Alt 再点击，只对这一次点击放行（鼠标变为手形）。

### 7.2 编辑模式内每个文字块的状态

- **空闲**：无任何高亮。
- **悬停**：鼠标在可编辑 host 上显示蓝色虚线框；在不可编辑但含文字的元素上显示灰色虚线框。
- **选中**：保留给 v0.2。v0.1 中单击直接进入编辑，选中与编辑合并。
- **编辑中**：绿色实线框，光标闪烁，浮动工具条显示。
- **提交中**：从触发提交到主进程返回，通常小于 50ms；期间保持绿框，新的输入被暂缓处理。
- **被拒**：进入或提交失败；框变红 600ms（降低动效时为静态红框 1.2 秒），同时显示气泡或提示，随后回到空闲。

### 7.3 状态转换表（事件，结果）

1. 空闲，鼠标移入可编辑 host：进入「悬停」（蓝框），状态栏显示该元素的面包屑。
2. 空闲，鼠标移入不可编辑含字元素：进入「悬停」（灰框），停留 600ms 后出现原因气泡。
3. 悬停，鼠标移出：回到空闲，气泡消失。
4. 悬停（可编辑），单击：期望校验通过则进入「编辑中」，光标落在点击位置；校验失败则「被拒」。
5. 悬停（不可编辑），单击：立即显示原因气泡（不等 600ms），保持 4 秒或直到鼠标移出；不进入编辑。
6. 编辑中，输入第一个字符：标签页出现未保存圆点。
7. 编辑中，Enter、Cmd/Ctrl+Enter 或 Esc：提交并退出。
8. 编辑中，Tab：提交并退出，同时进入下一个可编辑 host 的编辑；Shift+Tab 进入上一个。跳过不可见的 host（getClientRects() 为空、宽或高为 0，或 visibility 不为 visible）；目标不在视口内时，先滚动到可见（scrollIntoView，block: nearest）；到末尾循环到第一个。
9. 编辑中，点击页面其他位置：提交并退出；若点的是另一个可编辑 host，提交后立即进入它的编辑（一次点击完成切换）。
10. 编辑中，窗口失去焦点：提交并退出；回到应用后不自动恢复编辑。
11. 编辑中，Cmd/Ctrl+S：先提交，再保存，保持退出编辑；提示「已保存」。
12. 编辑中，Cmd/Ctrl+Z：若文字已偏离进入时的内容，交给浏览器按字词撤销；若与进入时一致，则提交（无变化）后执行应用级撤销。
13. 提交中，成功：回到空闲；刚编辑过的 host 用浅绿底淡出 400ms，作为「已记录」的反馈。
14. 提交中，失败：「被拒」，文字恢复为进入编辑时的内容。
15. 被拒，600ms 后：回到空闲。
16. 任意状态，切换到预览模式：先提交（若在编辑中），再关闭叠加层。
17. 任意状态，外部文件变更导致重载：先提交，再按 13.10 处理。
18. 任意状态，切换标签页：先提交，再切换；切回时恢复该标签的滚动位置与缩放，不恢复编辑状态。

### 7.4 提交的统一定义

- **提交**：把进入编辑后的变化生成 op，由主进程换算为补丁并更新 source，在撤销栈压入一项。
- 触发提交的事件：Enter、Cmd/Ctrl+Enter、Esc、Tab、点击别处、窗口失焦、保存、切换模式、切换标签页、外部变更、关闭窗口。
- 没有变化就不产生撤销项；第一次输入后又删回原样，未保存圆点随之消失。

## 8. 编辑交互细则

### 8.1 悬停

- 命中测试：取鼠标下最深的元素，向上找到第一个属于某个 host（或不可编辑含字元素）的元素，作为悬停目标。
- 悬停目标变化时，框在 80ms 内淡入淡出；不做位置动画，避免拖影。
- 光标：可编辑 host 为文本光标（I 形）；不可编辑含字元素与非文字区域保持页面自身光标。
- 页面自带的 hover 样式（例如按钮变色）继续生效，叠加层不拦截 hover。

### 8.2 单击进入编辑

- 光标位置：取点击坐标对应的文字位置（caretRangeFromPoint）；点在文字之后的空白处则落在行尾。
- 选区：默认不全选。双击选中一个词，三击选中整个 host 文字（浏览器默认行为，保留）。
- 进入编辑后，host 保持页面原有样式，不改变字体、字号、颜色与布局；只在叠加层上画绿框。host 获得 contenteditable=plaintext-only。
- 链接文字：编辑模式下单击不跳转，直接进入编辑；预览模式才跳转。按钮文字同理，不触发按钮功能；label 文字同理，不切换关联的表单控件。

### 8.3 输入与键盘（编辑中）

- Enter 或 Cmd/Ctrl+Enter：提交并退出。Shift+Enter：无效，状态栏轻提示「暂不支持换行」（不弹 toast）。
- Esc：提交并退出，保留修改。
- Tab 与 Shift+Tab：见 7.3 第 8 条。这是键盘用户逐段审阅文案的主要方式。
- 粘贴：只取纯文本，换行替换为一个空格；超过 5000 字符时截断并提示。
- 禁止：拖拽文字进编辑区；Cmd/Ctrl+B、I、U 等格式快捷键。
- 输入法：组合期间不提交、不拦截；上屏后才允许提交；组合期间按 Esc 只取消候选，不退出编辑。
- 右键：显示系统原生的文字菜单（剪切、复制、粘贴、全选）。

### 8.4 退出编辑

- 框消失；刚编辑过的 host 淡出一次浅绿底（400ms）。
- 不保留选区，避免用户误以为仍在编辑。

### 8.5 不可编辑的反馈

- 灰色虚线框；气泡内容 = 原因（一句话）+ 下一步（一句话），文案见 10.5。
- 气泡位置：元素下方 8px，水平方向夹紧在视口内；元素靠近底部时放上方；最大宽度 320px。
- 只对含文字的元素显示；纯布局元素与空元素不显示。
- 气泡不抢焦点；按 Esc 或鼠标移出后消失。

### 8.6 浮动工具条（v0.1 极简版）

- 进入编辑后显示，退出编辑后消失；位置按 9.4 的算法。
- 内容只有两个控件：「完成」按钮（等同 Enter，悬停提示含快捷键）；「更多」按钮（⋯），点开后有两项：撤销本次输入（等同在编辑中按撤销）、放弃本次修改（把 host 文字恢复为进入编辑时的内容并退出，不产生撤销项）。
- 放弃修改是编辑中唯一的「回退到进入时」入口，因为 Esc 已改为保留。
- 点击工具条按钮不得让 host 失去焦点（mousedown 阻止默认行为）。
- v0.3 起在这里加入文字格式按钮。

### 8.7 面包屑（v0.1 只读）

- 选中或编辑某个 host 时，状态栏左侧显示标签链，例如 body › main › section.hero › h1.title；最多 6 段，超出时中间用「…」省略；每段为标签名，加第一个 class（和 id，如果有）。
- 悬停每一段，用 title 显示完整选择器。
- 无选中时显示文件完整路径（过长时中间省略，悬停显示完整路径）。

### 8.8 预览模式

- 叠加层关闭，页面自身的点击、悬停、表单、动画全部放行。
- 点击 http/https 链接：弹确认框「在系统浏览器中打开 域名？」；其他协议不处理；页内锚点放行。
- 状态栏提示见 10.4；Esc 在预览模式下切回编辑模式。
- 切回编辑模式后，被脚本改动过的文字，会在下次点击时由期望校验（13.6）识别并拒绝。

### 9.2 设计令牌（深色）

- 应用外壳（工具栏、标签栏、状态栏、对话框）跟随系统深色模式；页面内容永远按页面自身样式渲染，不做反色。
- 背景 #14181F；面板 #1B2029；线条 #2B3442；正文 #E4E9F2；次要文字 #9AA7BD；accent #6EA4FF；edit #34D3A5；danger #FF7A93；预览底 #22262D。叠加层在深色页面上的框线不透明度提高到 85%。

### 9.3 叠加层元素的外观

- **悬停框（可编辑）**：1px 虚线，accent 65% 不透明，圆角 2px。
- **悬停框（不可编辑）**：1px 虚线，弱化色，圆角 2px。
- **编辑框**：1.5px 实线，edit 色；外圈 3px 光晕，edit 色 16% 不透明；左上角标签「文字」，edit 色底、白字、10.5px 等宽、圆角 3px。
- **选中框**（v0.2 起）：1.5px 实线，accent；光晕与标签同上，颜色为 accent；标签显示标签名与 id。
- **被拒闪烁**：框变 danger 色，600ms，一次，不循环。
- **已记录反馈**：刚编辑过的 host 淡出浅绿底（edit 色 14% 不透明），400ms。
- **标签位置**：框外左上角；距预览顶部不足 24px 时放到框内左上角。
- **气泡**：白底，1px 线条色边框，圆角 8px，阴影 0 10px 30px（阴影色 16% 不透明），内边距 8px 12px，最大宽度 320px；第一行是原因（正文色），第二行是下一步（次要文字色）。
- **浮动工具条**：白底，1px 线条色边框，圆角 12px，内边距 4px，阴影同气泡；按钮内边距 5px 8px，圆角 6px，悬停背景 #E9F1FF。

### 9.4 浮动工具条与气泡的定位算法（必须按此实现）

输入：目标元素矩形 r（视口坐标）、视口宽高 W 与 H、浮层宽高 w 与 h；边距 pad = 6。

1. x = 把 r.left 夹紧到 [pad, W − w − pad]。
2. 可见顶边 visTop = 把 r.top 夹紧到 [0, H]；可见底边 visBottom = 把 r.bottom 夹紧到 [0, H]。
3. 工具条优先放在元素上方：y = visTop − h − 8。（气泡优先放元素下方：y = visBottom + 8。）
4. 若放不下（工具条 y \< pad，气泡 y + h > H − pad）：改放另一侧，即工具条放可见顶边内侧 y = visTop + 8，气泡放元素上方。
5. 若仍溢出：元素下半部分可见时，工具条放可见底边上方 y = visBottom − h − 8；否则贴视口边缘 y = pad。
6. 最后把 x、y 夹紧在 [pad, W − w − pad] 与 [pad, H − h − pad] 内。
7. 浮层宽度超过视口时：x = pad，允许换行，最大宽度 = W − 2 × pad。
8. 位置在滚动、窗口大小变化、元素大小变化（ResizeObserver）时重新计算；不使用逐帧循环。

### 9.5 层级与动效

- 页内叠加层层级（z-index，叠加层内部）：悬停框 1，编辑框 2，气泡 3，浮动工具条 4。toast 与对话框属于应用外壳层，不在页内。
- 动效：时长 80 到 180ms，缓动 ease-out；只用透明度与不超过 8px 的位移；不做缩放与弹跳。
- 系统开启「减少动态效果」时：关闭淡入淡出；被拒闪烁改为静态红框 1.2 秒。

### 9.6 叠加层的实现约束

- 叠加层挂载在页面 documentElement 末尾，宿主元素 id 为 hw-overlay-root，使用 closed 影子 DOM；宿主 position: fixed、inset: 0、pointer-events: none，z-index 取最大值；仅内部的按钮与气泡开启 pointer-events: auto。
- 叠加层样式写在影子 DOM 内，页面样式无法影响；宿主用 all: initial 重置。
- 页面缩放（Cmd/Ctrl 加减）使用 Electron 的页面缩放，而不是 CSS 缩放，叠加层随之缩放且坐标一致。
- 叠加层不会出现在 13.6 的结构快照里（快照只遍历带 data-hw 的元素）。

## 10. 文案、空状态与提示

### 10.1 空状态（未打开文档）

- 中央卡片：标题「用鼠标点一点，改好页面上的文字」；副标题「打开一个 HTML 文件，直接在页面上修改文字。保存时只改动你改过的字。」；三个按钮：打开 HTML 文件（主按钮）、新建空白文档、载入示例页面；下方小字「也可以把文件直接拖进来」。
- 最近文件：最多 5 个，显示文件名与所在目录；文件已不存在时显示为灰色并标注「已移动或删除」，点击后提示并从列表移除。

### 10.2 示例文档

- 内置一份完整的示例 HTML，让新用户在 30 秒内体验：能改的地方、不能改的地方及其提示。以只读副本方式加载，点击保存时走「另存为」。
- 示例必须包含：普通标题与段落（可编辑）；含加粗的段落（可编辑）；一个由脚本生成的数字（不可编辑，展示原因气泡）；一个 pre 代码块（不可编辑）。

### 10.3 拖拽打开

- 文件拖到窗口上方时，整窗显示半透明遮罩与提示「松开，打开这个 HTML 文件」，副提示「可同时拖入多个」。
- 拖入非 HTML 文件：遮罩变为警示色，提示「只支持 .html / .htm」；松开后 toast 同样提示，不打开。
- 拖到 Dock 或任务栏图标、双击文件（系统文件关联）：与菜单「打开」等价。

### 10.4 状态栏操作提示（中间区域，随状态变化）

- 无文档：打开或拖入一个 HTML 文件开始
- 编辑模式空闲：点击文字直接修改 · Cmd/Ctrl+S 保存 · Cmd/Ctrl+E 预览
- 编辑中：Enter 完成 · Tab 下一处 · Esc 保留并退出
- 预览模式：页面按自身逻辑运行 · Esc 返回编辑
- 只读文件：只读：非 UTF-8 编码；或 只读：换行风格混杂
- 注：Windows 上 Cmd 显示为 Ctrl。

### 10.5 不可编辑原因与下一步（气泡，每条两行：原因 / 下一步）

- SCRIPT_GENERATED、MISMATCH：这段文字由页面脚本生成，或已被脚本改动，无法安全写回源码。 / 请在生成它的数据或脚本里修改。
- IN_PRE：预格式化文本（pre）暂不支持编辑。 / 可先在源码里修改，后续版本支持。
- IN_SVG：SVG 内的文字暂不支持编辑。 / 后续版本支持。
- IN_FORM_CONTROL：表单控件内的内容不属于页面文字。 / 无需修改文字时请忽略。
- BLOCK_CHILDREN：这段文字与块级元素混排，暂不支持编辑。 / 后续版本支持。
- IMPLIED_ELEMENT：该元素在源码中没有显式标签，暂不支持编辑。 / 可在源码里为它补上标签。
- COMMENT_IN_SLOT：这段文字中间夹有 HTML 注释，暂不支持编辑。 / 删掉注释，或把它移到文字之外。
- READONLY_FILE：文件为非 UTF-8 编码或换行风格混杂，仅可浏览。 / 用其他编辑器转换编码或统一换行后再打开。

### 10.6 toast 与对话框

- **toast**：预览区底部居中，距状态栏 16px；普通 2.2 秒消失，错误类 4 秒；同一时刻一条，新的替换旧的；Esc 可立即关闭；通过 aria-live 播报。
- toast 文案：保存成功「已保存」（副文字为文件名）；外部变更重载「已从磁盘更新」；结构被改变「这次修改改变了结构，暂不支持，已恢复」；粘贴过长「粘贴内容过长，已截断为 5000 字」。
- **对话框通用规则**：居中；宽 400px；标题加一句说明加按钮；主按钮在右；Enter 触发主按钮，Esc 触发取消；打开时焦点在主按钮（危险操作的默认焦点放在最安全的选项）。
- **关闭有未保存修改的标签或窗口**：标题「要保存对 文件名 的修改吗？」；说明「如果不保存，你的修改将会丢失。」；按钮：保存（主）、不保存、取消。
- **外部修改冲突**：标题「文件已被其他程序修改」；说明「你有尚未保存的修改，请选择保留哪一份。」；按钮：保留我的修改、载入磁盘版本、另存为…（默认焦点在「另存为…」，因为它不丢任何一方）。
- **保存失败**：标题「无法保存」；说明「系统给出的原因。你的修改仍保留在窗口中。」；按钮：重试（主）、另存为…、取消。
- **大文件（超过 10MB）**：标题「文件较大」；说明「打开可能比较慢。」；按钮：仍然打开（主）、取消。
- **只读示例点击保存**：直接弹出系统「另存为」对话框，不另行提示。
- **资源越界提示条**（应用外壳内，位于标签栏下方，高 32px；不遮挡预览、不抢焦点；每个标签页最多出现一次）：文案「这个页面引用了所在目录之外的文件（如 ../css/style.css），出于安全没有加载。」按钮：选择目录…（主）、忽略；右侧有关闭按钮。点「忽略」或关闭后，本标签页不再提示。
- **脚本渲染提示**（toast，4 秒）：「这个页面的正文由脚本渲染，大部分文字无法直接编辑」。页面加载完成 1 秒后，可编辑字符不足可见文字的 20% 时提示一次。

## 12. 技术栈与架构

### 12.1 技术栈

版本一律在开工当天取各自的稳定版，写入 package.json 并锁定。

- 桌面壳：Electron。理由：预览与用户在 Chrome 里看到的渲染一致。
- 语言：TypeScript（严格模式）。包管理：pnpm。构建：electron-vite 或同类工具。
- 应用外壳界面（工具栏、标签栏、状态栏、对话框、toast、空状态）：React，配轻量状态管理（如 Zustand）。预览区不是 React 组件，是独立的 WebContentsView。
- 叠加层与编辑层：不用框架，原生 TypeScript 加影子 DOM，打成单个 preload 脚本，压缩后体积目标小于 60KB。
- HTML 解析：parse5（开启 sourceCodeLocationInfo）；实体解码：entities 包；文件监听：chokidar。
- 设置持久化：JSON 文件，放在应用数据目录（窗口状态、最近文件、缩放、视口宽度、按文件路径记住的资源根授权）。
- 测试：Vitest（单元）、Playwright 的 Electron 支持（端到端）。打包：electron-builder；代码签名与公证不在 v0.1 范围。

### 12.2 进程与视图

- **主进程**：文件读写、编码检测、parse5 解析与槽位表、补丁引擎、撤销栈、文件监听、自定义协议、窗口与菜单、IPC 路由。对 source 的一切修改只发生在主进程。
- **应用外壳（React）**：只通过 IPC 发指令、收状态；不接触文档内容。
- **预览视图（每个标签页一个 WebContentsView）**：只显示当前标签的视图，其余隐藏但不销毁（保留页面状态与滚动）；标签数上限 20，超过时提示「请先关闭一些标签页」。
- **preload（预览视图内，隔离世界）**：创建叠加层；监听鼠标与键盘；做结构快照；向主进程发送 op；页面脚本读不到它的变量。

### 12.3 IPC 通道（名称、方向、内容）

- doc:open（外壳到主）：路径列表；主进程回 doc:opened（标签 id、文件名、是否只读、可编辑块数量）。
- doc:save、doc:saveAs（外壳到主）：标签 id；主进程回 doc:saved 或 doc:saveFailed（原因）。
- doc:state（主到外壳）：标签 id、dirty、能否撤销、能否重做、只读原因。
- mode:set（外壳到主到预览）：编辑或预览。
- hover:info（预览到外壳）：面包屑字符串、悬停目标是否可编辑、原因代码。
- edit:enter（预览到主）：eid 与快照；主进程回 edit:enterResult（ok 或原因代码）。
- edit:commit（预览到主）：ops 数组与进入时的快照；主进程回 edit:commitResult（ok 或错误）。
- edit:sync（主到预览）：ops 数组；撤销与重做后同步预览 DOM。
- edit:abandon（预览到主）：放弃本次修改，不产生撤销项。
- toast（主到外壳）：级别与文案。
- page:stats（预览到外壳）：可见文字字符数、可编辑字符数；页面加载完成 1 秒后计算一次，用于脚本渲染提示（10.6）。
- res:outOfRoot（主到外壳）：越界请求所在的目录列表，用于显示资源越界提示条。res:grantRoot（外壳到主）：用户选择的资源根目录。
- 所有通道都带标签 id；主进程必须校验消息确实来自该标签对应的预览视图。

## 13. 数据结构与核心算法

### 13.1 数据结构

```ts
type Eid = number;

interface ElementInfo {
  eid: Eid;
  tag: string;               // 小写标签名
  parent: Eid | null;        // 父元素为隐含元素时为 null
  children: Eid[];           // 直接子元素 eid（仅显式出现的）
  slots: SlotInfo[];         // 长度 = children.length + 1
  isHost: boolean;
  hostId?: Eid;              // 若属于某 host，指向该 host
  uneditableReason?: ReasonCode;
}

interface SlotInfo {
  start: number;             // 槽在 source 中的起点（UTF-16 偏移）
  end: number;               // 终点（不含）；空槽 start === end
  raw: string;               // 源码原文，可含实体
  text: string;              // 解码后的文字
  tokens: Token[];           // 实体 token 化结果，见 13.7
  hasComment: boolean;       // 槽内是否夹有注释节点
}

interface Token { rawStart: number; rawEnd: number; decoded: string; }
interface SetSlotOp { eid: Eid; slot: number; newText: string; }
interface Patch { start: number; end: number; text: string; }

interface UndoEntry {
  forward: Patch[];          // 已应用的补丁
  inverse: Patch[];          // 撤销用补丁（坐标为应用后的 source）
  ops: SetSlotOp[];          // 同次提交的 op
  inverseOps: SetSlotOp[];   // 撤销时通知预览同步用
  coalesceKey?: string;      // 合并键，见 13.9
  at: number;                // 时间戳（毫秒）
}

interface TabState {
  id: string;
  path: string | null;       // null = 新建、尚未保存
  resourceRoot: string;      // 资源根目录，默认为文件所在目录，见第 14 节
  source: string;
  version: number;
  eol: 'LF' | 'CRLF';
  hasBom: boolean;
  readOnly: ReasonCode | null;
  undo: UndoEntry[];
  redo: UndoEntry[];
  savedAt: number;           // 保存点在 undo 栈中的位置
  diskHash: string;          // 最近一次读取或写入时的磁盘内容哈希
  mode: 'edit' | 'preview';
}

type ReasonCode =
  | 'SCRIPT_GENERATED' | 'MISMATCH' | 'IN_PRE' | 'IN_SVG'
  | 'IN_FORM_CONTROL' | 'BLOCK_CHILDREN' | 'IMPLIED_ELEMENT'
  | 'COMMENT_IN_SLOT' | 'READONLY_FILE';
```

### 13.2 打开文件

1. 读取文件为 Buffer。若以 EF BB BF 开头，记录 hasBom = true 并去掉这 3 字节。
2. 以严格 UTF-8 解码；失败则只读打开（READONLY_FILE）。
3. 统计 CRLF 与单独 LF 的数量：两者并存则只读打开；只有 CRLF 则 eol = CRLF，并在内存里把 CRLF 全部换成 LF；其余情况 eol = LF。保存时 eol 为 CRLF 则再换回。
4. 文件大于 10MB：先弹「文件较大」对话框（见 10.6）。
5. source = 解码后的字符串；version = 0；撤销与重做栈为空；savedAt = 0；diskHash = 磁盘原始字节的 SHA-256。
6. 加入最近文件列表（最多 10 个，去重，最新在前）。
7. 同一路径已在某标签中打开：直接切换到该标签，不新开。

### 13.3 解析与建表

1. 用 parse5 对 source 做完整文档解析，开启 sourceCodeLocationInfo。
2. 深度优先遍历，按文档顺序给每个带起始标签位置信息的元素分配 eid。没有起始标签位置的元素（被隐含的 html、head、body、tbody 等）不分配，称为隐含元素。
3. 对每个有 eid 的元素划分槽：相邻子元素之间的文本节点区间成为一个槽，start 与 end 取自该文本节点的位置信息；该位置没有文本节点时，空槽的 start = end = 前一个兄弟元素的结束位置，没有前一个兄弟则取本元素起始标签的结束位置。
4. 槽内出现注释节点：hasComment = true，该槽整体不可编辑（COMMENT_IN_SLOT）。
5. 为每个槽计算 text 与 tokens（见 13.7）。

### 13.4 host 判定规则（纯函数，必须单独写单元测试）

对每个元素 E，按顺序判定，命中即停：

1. E 的标签在黑名单中：E 及其整棵子树不可编辑。黑名单：script、style、noscript、template、textarea、select、option、iframe、object、embed、canvas、video、audio、svg、math、pre、head 及其子孙（含 title）。
2. E 没有 eid（隐含元素）：不是 host，继续判定它的子元素。
3. 若 E 的所有子孙元素的标签都在内联白名单里，并且 E 的某个槽含有非空白文字，则 E 是 host 候选。内联白名单：a、abbr、b、bdi、bdo、br、button、cite、code、data、del、dfn、em、i、ins、kbd、label、mark、q、s、samp、small、span、strong、sub、sup、time、u、var、wbr；另有原子内联 img、svg 与 input，可以出现在 host 里，但其内部不扫描、不可编辑（input 的值同样不可编辑）。例：`<p>点击<button>这里</button>继续</p>` 与 `<label><input type="checkbox"> 我已阅读</label>` 整体各成为一个 host。
4. 自外向内，最外层的 host 候选成为 host；它的所有子孙归属该 host，不再单独成为 host。E 自己的标签可以是任意非黑名单标签（li、h1、button、td 等都可以成为 host）。
5. 含文字但不满足第 3 条的元素：它的非空白槽标记为不可编辑，原因按情形取 BLOCK_CHILDREN、IN_PRE、IN_SVG、IN_FORM_CONTROL。
6. 只含空白的槽不算文字，不参与高亮和统计。

### 13.5 带标注副本

1. 对每个有 eid 的元素，在其起始标签里标签名之后插入文本 ` data-hw=eid`（前面带一个空格，属性值不加引号，eid 是纯数字，这种写法合法）。插入位置 = startTag.startOffset + 1 + 标签名原文长度（按源码原文长度算，大小写不变）。
2. 必须从后往前插入，避免偏移错位；其余字节原样不动。
3. 该副本只存在于内存，由自定义协议提供给预览；它与磁盘文件无关，不得写回。

### 13.6 编辑流程（预览端 preload 与主进程协作）

**进入编辑**（编辑模式下单击 host H）：

1. preload 对 H 做快照：H 及其所有带 data-hw 的后代元素，记录每个元素的子元素 eid 序列，以及每个槽当前的文字（槽内连续文本节点的 data 拼接起来）。
2. 发送 edit:enter，主进程做期望校验：（a）H 内每个元素都必须带 data-hw；（b）每个槽的快照文字必须与 source 中该槽解码后的文字完全相等；（c）H 内没有 COMMENT_IN_SLOT 的槽。任一不满足，拒绝进入编辑，提示 MISMATCH 文案（含义：页面脚本改动了这里）。
3. 通过后，preload 给 H 设置 contenteditable=plaintext-only，用 caretRangeFromPoint 把光标放到点击位置，并记录进入时的文字作为基线。
4. 拦截 beforeinput：insertParagraph、insertLineBreak、insertFromDrop 以及所有以 format 开头的类型，一律 preventDefault；insertFromPaste 改为按 8.3 处理；historyUndo 与 historyRedo 按 7.3 第 12 条有条件放行。输入法组合期间的事件不可取消，不要尝试拦截，只在 compositionend 之后才允许提交。

**提交编辑**（7.4 所列事件触发）：

1. preload 再对 H 做一次快照。
2. 结构校验：H 内每个元素的子元素 eid 序列必须与进入时完全一致。不一致（例如删除跨过了内联标签边界）：把 H 恢复为基线，提示「这次修改改变了结构，暂不支持，已恢复」，不产生 op。
3. 逐槽比较文字，凡有变化的槽生成一个 setSlot op。新文字中的 U+00A0（不换行空格），若该槽旧文字中没有，一律换成普通空格（浏览器会在连续空格处自动插入它）。
4. 没有任何变化则不产生 op，直接退出编辑。
5. 发送 edit:commit；成功则回复 ok，失败则 preload 把 H 恢复为基线并显示「被拒」状态。
6. 移除 contenteditable，退出编辑。

**放弃本次修改**（浮动工具条「更多」菜单）：把 H 恢复为基线，发送 edit:abandon，退出编辑，不产生撤销项。

提交成功后预览不重新加载：DOM 已是新内容，且只改文字不改结构，eid 不变。

### 13.7 op 换算成补丁（最小改动）

1. 取 op 对应的槽，旧文字记为 old，新文字记为 nw。
2. 求 old 与 nw 的最长公共前缀长度 p，以及最长公共后缀长度 s（后缀不得与前缀重叠）。前缀和后缀的切点必须落在 UTF-16 代理对（如 emoji）的边界上，不能把一个字符切成两半。
3. 变化区间在解码文字上是 old 的 [p, old.length − s)，替换为 nw 的 [p, nw.length − s)。
4. 解码偏移到源码偏移的映射靠 tokens：把槽的原文切成顺序 token，普通字符每个 UTF-16 单元一个 token，每个字符实体（如 \&amp;、\&copy;、\&#x4e2d;）整体一个 token，各 token 记录原文区间和解码后的文字。变化区间的起点向左对齐到 token 边界、终点向右对齐到 token 边界；若因此把旧文字中的一部分扩进了区间，要把这部分旧文字补回新片段的两端。
5. 转义新片段：& 写成 \&amp;，\< 写成 \&lt;，> 写成 \&gt;，U+00A0 写成 \&nbsp;。其他字符（含中文、emoji、引号）原样写入，不转义。
6. token 化自检：所有 token 的解码文字拼接后，必须等于 parse5 给出的该槽文字。不相等（例如遇到没有分号的旧式实体）则退化为「整槽一个 token」，写回时整槽替换并转义，同时写一条 warning 日志。
7. 一次提交含多个 op 时，各补丁区间互不重叠（不同槽）。按 start 从大到小应用到 source。每个补丁生成逆补丁，逆补丁的坐标是应用后 source 中的坐标：start' = start + 此前所有补丁（按 start 从小到大）造成的长度变化之和，end' = start' + 新文本长度，text 为旧原文。
8. 应用后：source 更新，version 加 1，重新解析整份 source（v0.1 不做增量解析）。自检「结构不变」：eid 总数、每个元素的 children 序列必须与应用前完全相同。不同则回滚补丁，报错并写日志（这是保险丝，正常情况不应触发）。
9. 空槽插入（槽原本为空、用户输入了文字）：锚点必须明确，即槽的 start 来自起始标签的结束位置，或来自前一个兄弟元素的显式结束标签。若前一个兄弟省略了结束标签，拒绝本次编辑，按 MISMATCH 处理。

### 13.8 保存与另存为

1. Cmd/Ctrl+S：source →（eol 为 CRLF 则把 LF 换回 CRLF）→（hasBom 则加回 BOM）→ UTF-8 字节。
2. 写入前比较磁盘文件当前内容的哈希与 diskHash；不一致，进入 13.10 的冲突流程，不写入。
3. 原子写入：先写到同目录的临时文件，刷盘后重命名覆盖原文件，并保持原文件权限。Windows 上重命名失败时，退回直接覆盖写入。原文件是符号链接时，写入链接指向的目标。
4. 成功：savedAt 记为当前撤销栈位置，更新 diskHash，撤销栈保留；提示「已保存」。
5. 失败（权限、只读、磁盘满）：弹出「无法保存」对话框，保持未保存状态，内存中的修改不丢。
6. 无路径的新建文档、只读示例：Cmd/Ctrl+S 等同「另存为」。
7. 另存为：弹出系统保存对话框，默认文件名为原文件名（无则「未命名.html」）；成功后更新标签名、path、diskHash 与保存点；若保存目录与原目录不同，预览重新加载一次并保持滚动位置（相对路径资源的基准目录变了），resourceRoot 重置为新目录（原授权不沿用），资源缺失时在状态栏提示。

### 13.9 撤销与重做

1. 撤销栈每次提交一项 UndoEntry，不设上限（每项只存补丁，体积很小）。新提交会清空重做栈。
2. 合并规则：同一标签页、coalesceKey 相同（格式 eid:slot）、且与上一项间隔不超过 600ms 的连续提交，合并为一项。v0.1 中因为一次编辑只提交一次，基本不会触发；为 v0.3 之后的连续微调预留。
3. 撤销：取栈顶，对 source 应用 inverse 补丁，version 加 1，整份重新解析；同时向预览发送 edit:sync（inverseOps）。重做同理，使用 forward 与 ops。
4. 预览同步函数 setSlotText(eid, slot, text)：在预览 DOM 里找到 data-hw 等于 eid 的元素，按子元素 eid 序列切分它的 childNodes，找到第 slot 个槽；删除槽内所有文本节点，若 text 非空，则在槽的位置创建一个新的文本节点。
5. 脏标记：dirty = 撤销栈当前位置不等于 savedAt，或当前有未提交的输入。因此撤销回保存点时，未保存圆点要消失。
6. 重新加载磁盘版本时清空两个栈，savedAt 归零。

### 13.10 外部变更

1. 用 chokidar 监听每个打开的文件，开启写入稳定等待（200ms 内无变化才触发）。
2. 事件触发后读取磁盘内容并计算哈希；与 diskHash 相同，视为本应用自己的写入，忽略。
3. 不同，且没有未保存修改：静默重载，即重新读取、解析，重建预览并保留滚动位置，清空撤销栈，toast 提示「已从磁盘更新」。
4. 不同，且有未保存修改：弹出「文件已被其他程序修改」对话框（见 10.6）。选择「保留我的修改」后，下次保存覆盖磁盘；选择「载入磁盘版本」则丢弃内存修改并重载；选择「另存为…」则把当前内容存到新路径，原路径不变。
5. 文件被删除或重命名：提示一次，保留内存内容，保存时走「另存为」。
6. F5 等同于「载入磁盘版本」；有未保存修改时先弹确认。

### 13.11 多标签页

- 每个标签页 = 一份 TabState + 一个预览视图；标签之间互不影响。
- 新建空白文档：source 为最小模板（doctype；html 的 lang 为 zh-CN；head 里 meta charset 为 utf-8、title 为「未命名」；body 里一个 h1「标题」和一个 p「在这里输入正文。」），path 为 null，首次保存走「另存为」。
- 关闭标签页：有未保存修改时弹对话框（见 10.6）；关闭最后一个标签页后回到空状态，窗口不关闭；空状态下 Cmd/Ctrl+W 关闭窗口。
- 标签页可在标签栏内拖动重排；不支持拖出成新窗口。
- v0.1 不做会话恢复：重新启动应用后不自动恢复上次打开的标签。

## 14. 预览加载与安全

- **自定义协议 hw://**：注册为 standard 且 secure。每个标签页使用独立的主机名（hw://t-标签id/）以隔离。URL 路径等于文件在磁盘上的绝对路径（Windows 以盘符为第一段，如 /C/Users/…/report.html）；入口即该文件自身的 URL，返回带标注副本（text/html; charset=utf-8）。这样页面里的 ../ 由浏览器按真实目录层级解析，主进程收到的就是目标文件的真实路径，才能判断是否越界。
- **资源根目录（resourceRoot）**：默认为被打开文件所在目录。请求的真实路径（含符号链接展开）位于资源根内，则返回该文件。以 / 开头的根相对路径，若按绝对路径不在资源根内，再按「资源根 + 该路径」解析一次。
- **越界处理**：两种解析都不在资源根内时返回 404。若该文件在磁盘上确实存在（页面引用了上级目录的资源），主进程记录其所在目录，通过 res:outOfRoot 通知外壳显示资源越界提示条（10.6）。
- **授权上级目录**：用户在提示条上点「选择目录…」，弹出系统目录选择框，默认定位到所有越界目录与文件所在目录的最近公共上级目录。所选目录必须是文件所在目录本身或它的上级，否则提示并忽略。授权后更新 resourceRoot，重新加载预览并保留滚动位置。授权按文件路径记入设置，下次打开同一文件时自动沿用。资源根之外的请求仍一律返回 404。
- **已知问题**：页面脚本可以从 location 读到文件的本地绝对路径（可能含用户名）。v0.1 接受这一行为。
- **webPreferences**：sandbox 开启、contextIsolation 开启、nodeIntegration 关闭、webSecurity 开启、不允许不安全内容；使用专用的内存会话分区，关闭后 cookie 与 localStorage 随之清除。
- **权限**：对预览会话的所有权限请求与权限检查一律拒绝（摄像头、麦克风、地理位置、通知、剪贴板读取等）。
- **导航与窗口**：页面内跳转（will-navigate）与 window.open 一律阻止；下载一律取消。外链只在预览模式下，由应用弹确认后交给系统浏览器（见 8.8）。
- **网络**：允许加载 http/https 的外部资源（AI 页面常用 CDN）。通过请求拦截禁止 file:// 以及 hw、http、https、data、blob 之外的协议。外部资源加载失败时，状态栏提示「部分外部资源加载失败」。
- **不注入 CSP**：避免破坏页面本身的行为；隔离靠沙箱与权限控制。
- **编辑层脚本只放在 preload**：运行在隔离世界，先于页面脚本执行；页面脚本读不到它的变量，但两者共享 DOM。

## 15. 边界情况（情况，行为）

- 页面脚本在运行时改写了静态文字：进入编辑时期望校验失败，拒绝，提示 MISMATCH。
- 文字由 JS 拼接、伪元素、CSS content 生成：源码里没有对应槽，高亮为灰色，提示「由页面脚本生成」。
- CSS text-transform 改变了显示大小写：编辑时用户看到转换后的样子，写回的是用户实际输入的字符；已知行为，不处理。
- 槽内夹有 HTML 注释：整个槽不可编辑（COMMENT_IN_SLOT）。
- 元素带 br：br 前后是不同的槽，各自独立编辑；Enter 被禁用，所以无法新增 br。
- 属性里的文字（alt、title、placeholder）、meta、title 标签内容：不可编辑。
- 源码标签大小写混用或自闭合写法（如 BR 或 br/）：按原文长度计算插入位置，不改写。
- emoji 与全角字符：偏移一律按 UTF-16 单元计算，前缀后缀切点对齐代理对边界。
- 文件超过 10MB：打开前弹「文件较大」对话框，用户确认后仍可打开。
- 源码里已经带有 data-hw 属性的元素：副本里本应用插入的属性排在前面，以先出现者为准；极罕见，不额外处理。
- 页面里有 iframe：iframe 内文字不可编辑，且 iframe 本身不处理点击。
- 表单控件的输入值（input、textarea、select）：不属于文字槽，不可编辑。
- 页面自带全屏遮罩、固定定位的元素盖住了文字：命中测试取最上层元素，找不到 host 则不高亮；用户可切到预览模式关闭遮罩。
- 页面用 CSS 把文字设为 user-select: none：编辑模式下不影响进入编辑（contenteditable 会覆盖）。
- 窗口缩放或预览缩放比例变化：叠加层按 9.4 重新定位，进行中的编辑不受影响。
- 标签页在后台时文件被外部修改：切回该标签时再按 13.10 处理，不在后台弹对话框。
- 应用异常退出：v0.1 不做崩溃恢复，未保存的修改会丢失；对话框与未保存圆点是主要防线。
- 隐藏内容（标签页、折叠面板、轮播、弹窗里暂时不可见的文字）：无法悬停，Tab 也会跳过。需要编辑时，先切到预览模式把它展开，再切回编辑模式（切换模式不重载页面，展开状态保留）。
- 在浏览器端由框架渲染正文的页面：可以打开和预览，正文显示为 SCRIPT_GENERATED；可编辑字符不足可见文字的 20% 时提示一次（10.6）。
- 页面引用上级目录的资源（如 ../css/style.css）：默认不加载，并显示资源越界提示条；授权上级目录后正常加载（第 14 节）。
- host 内的 button、label、input：编辑模式下不触发按钮、不切换表单控件；用退格删掉 input 等原子元素属于结构改变，由提交时的结构校验恢复（13.6）。

### 17.4 真实样本集与覆盖率口径

- **原始样本集**（用于门槛）：至少 30 个真实 AI 生成的单文件 HTML 页面，放在 tests/fixtures/real/（脱敏后）。构成建议：落地页 10、报告或文章 8、幻灯片式页面 6、带交互的页面（计算器、仪表盘、图表）6。来源：用同一批 10 个提示词，在不同 AI 上各生成一遍（待确认 Q6）。提示词中不得包含任何写法约束。
- **约束样本集**（参考指标，不作门槛）：放在 tests/fixtures/real-guided/。同一批提示词末尾附加附录 A.3 的约束提示词，在同样的 AI 上再生成一遍。用于衡量推荐写法能带来多少提升，数据供宣传与 demo 使用（附录 A.4）。
- **口径**：可见文字字符数 = 页面渲染后 innerText 去掉空白后的字符数；可编辑字符数 = 属于某个 host、通过校验、且位于可见元素内的槽中，去掉空白后的字符数（分子与分母都只计可见文字，隐藏内容两边都不计）。覆盖率 = 可编辑字符数 ÷ 可见文字字符数。
- **脚本渲染页**：SCRIPT_GENERATED 字符占可见文字 50% 以上的页面，单独列出，不计入门槛。
- **门槛**：原始样本集中，排除脚本渲染页之后，按字符加权的总覆盖率不低于 80%。按页面平均的覆盖率同样输出，作为参考。
- **脚本**：pnpm coverage 用无界面的 Chromium 渲染页面，复用 preload 中计算可见文字与可编辑文字的逻辑（与 page:stats 同一实现），并在加载完成 1 秒后统计。分两套样本集，输出每页覆盖率、两种总覆盖率、不可编辑原因分布与脚本渲染页清单。
- **用途**：M1 中先跑一次初测（只依赖 parse.ts 与 host-rules.ts 的初版），结果决定 BLOCK_CHILDREN 是否在 v0.1 放宽（19.1 Q4）；M4 再跑一次终测，用于 AC-40。

## 20. 后续版本设计要点（不实现，仅为架构预留）

### 20.1 总原则

所有后续编辑仍然走 op、补丁、source 这一条路径；每种新操作都必须能换算成对 source 的区间替换，并带逆补丁。叠加层、状态机、定位算法、视觉令牌全部复用。

### 20.2 v0.2 选择模式（对应 demo 的组件模式）

- 元素的源码范围 = 起始标签的起点到结束标签的终点（空元素到起始标签的终点）；要求起止标签都显式存在。
- **删除**：删除该范围；范围独占整行时，连同前导缩进与行尾换行一起删除，让 diff 干净。
- **复制**：把该范围的原文插到原范围之后，保持缩进；新元素的 eid 在重新解析后产生。
- **移动**：先确定目标位置（相邻元素之前或之后），把范围原文剪切并插入目标位置；目标不能在被移动元素内部；li 只能在 ul 或 ol 内移动，tr 只能在同一表体内移动，否则拒绝并提示。
- **撤销**：由多段逆补丁完成，坐标为应用后的 source。
- **交互**：单击选中（选中框与标签）；双击进入文字编辑；Tab 进入或离开选择模式；面包屑可点击；Alt+上下选父子；Delete 删除；Cmd/Ctrl+D 复制；拖放换位（pop 色拖放线 3px，拖动阈值 5px，被拖元素半透明）；「显示空白」用粉色虚线框标出没有文字也没有媒体的容器。
- **导出 PDF**：用 Electron 原生打印到 PDF。

### 20.3 v0.3 样式与文字格式

- **样式写入 style 属性**：已有 style 则按声明解析，只改目标声明，保持其他声明与顺序；没有则在起始标签的标签名之后插入。支持「重置」：删除对应声明，声明为空则删除整个 style 属性。
- **属性面板**：右侧，宽 280px，可收起；颜色、字号、对齐、行距即时预览、即时补丁。作用域 v0.3 只做「仅此元素」。
- **尺寸手柄**：右、下、右下三个手柄；拖动时显示「宽 × 高」；写入 width 与 height（px）。demo 在 flex 容器里会同时冻结 flex-grow、flex-shrink、flex-basis，副作用较大；v0.3 在这种情况下弹一次性提示，并提供「重置」。同时提示像素尺寸会降低响应式表现。
- **文字格式**：加粗、斜体、下划线、删除线、上标、下标，由补丁引擎在槽内对选区插入或移除对应的内联标签（b、i、u、s、sup、sub），不使用 execCommand；依赖 13.7 第 4 条的 token 映射；选区跨越内联标签边界时拆分后重新嵌套，失败则拒绝并提示。
- **媒体插入**：选择文件后复制到文档同目录下的 assets 文件夹（重名加序号），在光标或选中元素之后插入带相对路径的 img、video、audio；超过 12MB 时提示；不做 base64 内嵌。
- **粘贴与导入**：复制选中元素的原文到应用剪贴板，可粘贴到其他标签；可从其他 HTML 文件导入正文片段；样式冲突时提示。

### 20.4 v0.4 位置与组件规范

- **方向键微调**：对选中元素写入 position: relative 与 left、top（1px，Shift 为 10px）；连续按键 600ms 内合并为一步撤销（13.9 第 2 条）；明确提示「视觉偏移，不改文档流」，可一键重置。
- **组件规范**：data-c 标组件类型，data-slot 标槽位，data-id 由编辑器的规范化步骤注入，配套校验器与分级编辑（Level 1）。立项时单独出规格；本版只预留：eid 与槽的概念不依赖文字内容，可扩展到属性与结构编辑。

### 20.5 v0.5 协作

- 文件变更三方合并：以 eid 加槽为单位，对比「打开时版本、内存版本、磁盘版本」，无冲突自动合并，冲突在界面里逐项选择。
- 导出 Markdown 与纯文本。

### 20.6 架构预留清单

- op 类型设计为可扩展的联合类型（现在只有 setSlot）。
- 补丁引擎与 op 无关，只处理区间替换与逆补丁。
- 状态机里的「选中」状态已预留；浮动工具条的内容由当前模式与选中类型决定，便于增加按钮。
- 视觉令牌集中在一个文件，浅色与深色同构。
- 文案集中在 messages.ts，便于以后做多语言。

## 附录 A　推荐的 HTML 写法（对外材料，不属于 v0.1 产品功能）

用途：后续宣传、使用介绍与 demo 演示；同时是 17.4 约束样本集的生成提示词。内容与 13.4、10.5、第 14 节的规则一一对应，规则变化时同步更新本附录。

### A.1 可以直接编辑的写法

1. 文字直接写在 HTML 源码里。
2. 装文字的元素里只放内联标签：a、strong、b、em、i、u、s、del、ins、span、code、mark、small、sub、sup、br、label、button，以及图片与图标（img、svg）、输入框（input）。
3. 起始标签与结束标签都写全，不依赖浏览器自动补齐。
4. 文件使用 UTF-8 编码，换行风格统一。
5. 图片、样式、脚本等本地资源放在 HTML 所在目录或其子目录里，用相对路径引用；CDN 资源可以正常使用。

### A.2 无法编辑或需要额外操作的写法

| 写法 | 例子 | 结果 | 建议改为 |
|---|---|---|---|
| 正文由脚本生成 | React、Vue、Alpine 渲染；innerHTML 拼接 | 不可编辑（SCRIPT_GENERATED） | 正文直接写进 HTML，脚本只负责交互 |
| 运行时被脚本改写的文字 | 计数动画、打字机效果 | 不可编辑（MISMATCH） | 初始文字写成最终文字 |
| 文字与块级元素混排 | `<div>标题<p>正文</p></div>` | 不可编辑（BLOCK_CHILDREN） | `<div><h3>标题</h3><p>正文</p></div>` |
| 文字中间夹注释 | `<p>甲<!-- 注 -->乙</p>` | 不可编辑（COMMENT_IN_SLOT） | 注释移到文字之外 |
| 特殊容器内的文字 | pre、svg、textarea、canvas、iframe | 不可编辑（IN_PRE、IN_SVG、IN_FORM_CONTROL） | 无 |
| 属性与元信息里的文字 | alt、title、placeholder、`<title>`、CSS content | 不可编辑 | 无 |
| 引用上级目录的资源 | `../css/style.css` | 默认不加载，需授权一次上级目录 | 资源放进同目录或子目录 |
| 非 UTF-8 或换行混杂 | GBK 编码的文件 | 只读 | 转为 UTF-8 并统一换行 |
| 隐藏内容 | 标签页、折叠面板、弹窗 | 可编辑，但需先在预览模式展开 | 无 |

### A.3 给 AI 的约束提示词（可直接复制）

```
请生成一个单文件 HTML 页面，并遵守以下写法，方便之后在可视化编辑器里直接修改文字：
1. 所有可见文字直接写在 HTML 里，不要用 JavaScript 生成或改写正文；图表、计算结果等确实需要脚本的部分除外。
2. 每段文字放在自己的元素里（h1–h6、p、li、td、button、span 等），不要把文字和 div、p 等块级元素并排放在同一个父元素里。
3. 文字内部只使用 a、strong、em、b、i、u、s、del、ins、span、code、mark、small、sub、sup、br 这些内联标签。
4. 不要在文字中间写 HTML 注释。
5. 标签成对写全，使用 UTF-8 编码。
6. 需要本地图片或样式时，放在与 HTML 同目录或其子目录，用相对路径引用；也可以使用 CDN。
```
